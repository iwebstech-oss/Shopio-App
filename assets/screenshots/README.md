# Play Store Screenshots

## Required Screenshots for Google Play Store

### Phone Screenshots (Required):
- [ ] Home/Dashboard Screen
- [ ] Product Listing Screen  
- [ ] Product Detail Screen
- [ ] Shopping Cart Screen
- [ ] Checkout Screen
- [ ] Login/Registration Screen
- [ ] User Profile Screen

### Tablet Screenshots (Optional but Recommended):
- [ ] Home/Dashboard Screen
- [ ] Product Listing Screen

## Instructions:
1. Run the app on emulator/device
2. Take screenshots of each screen
3. Save as PNG files in this folder
4. Name them appropriately: phone_1_home.png, phone_2_products.png, etc.

## Screenshot Naming Convention:
- Phone: phone_01_screen_name.png
- Tablet: tablet_01_screen_name.png

## Dimensions:
- Phone: 320-3840px width, 320-3840px height
- Tablet: 600-7680px width, 600-7680px height
